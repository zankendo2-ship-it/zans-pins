# Evidence bundle for 2026-11-28
Courses: bangor_on_dee, doncaster, fairyhouse, newbury, newcastle, southwell. Built 2026-11-28T10:25Z from the racing branch (read only). TEST data for advisory review; never on the slip.

- runners_evidence_prerace.csv: the frozen pre-race evidence pack for every runner (form coverage, trainer/jockey records, draw and pace fit, market). Racing Post RPR / Topspeed columns and comments are WITHHELD (licence); they are visible only as the numbers quoted in the sealed picks' reasons.
- racecard_data/: connections, form coverage, form check, speed figures and pace map (our own figures), runner list.
- track_dna/: our Track DNA reports per course, accepted evidence (short sourced quotes), quality checks. Full third-party guide text is not copied.
- methods/: the ZANS course method file per course and race code racing today, with its rule change log.
- course_knowledge/: our course knowledge base file per course and code (draw, pace, weight, trainers, jockeys with A/E and sample sizes).
- track_stats/: national draw, pace and weight tables for these courses.
- history/runner_past_runs.csv: every earlier run in our history for today's runners (2018 to date): date, course, race type, class, distance, going, field size, finish position, draw, weight, official rating, SP, jockey, trainer. Matched by horse name, so a reused name can add an older horse's runs (known limit). Racing Post ratings, times and comments withheld. The full historical database (about 1 GB of results across several files) is NOT published; this extract is its slice for today's runners.
